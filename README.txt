SUPERmerda PWA
================
Arquivos:
- index.html: jogo enviado pelo desenvolvedor
- manifest.webmanifest: configuração PWA
- service-worker.js: cache/offline
- icon-192.svg / icon-512.svg: ícones

Como publicar:
1. Publique esta pasta em um servidor HTTPS.
2. Abra o endereço do site no navegador e teste.
3. No PWABuilder, informe a URL pública do jogo.
4. Corrija qualquer requisito apontado pela análise.
5. Use a opção Android/TWA oferecida pelo PWABuilder para gerar o pacote Android.

Observação:
O PWABuilder trabalha com uma URL pública HTTPS; este ZIP é o pacote do site/PWA, não um APK já compilado.
